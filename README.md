# Furniro — furniture store landing

Front-end demo of a furniture store landing page, built with **HTML, CSS and vanilla JavaScript** (no frameworks, no build step).

**Live demo:** https://strukk311.github.io/furniture-store-landing/

## Features
- Responsive layout: desktop, tablet, mobile (burger menu, touch-friendly product cards)
- Product catalogue rendered from JS data, room filters, live search, "Show more / Show less"
- Product hover overlay: Add to cart, Share (Web Share API / copy link), Compare (up to 3), Like
- Cart drawer: add, change quantity, remove, subtotal; cart and wishlist saved in `localStorage`
- Demo checkout with form validation (no real payment)
- Newsletter form with email validation
- Tips & Tricks slider: scroll-snap, arrows, dots, swipe on mobile
- Page-load animation in the hero and scroll reveal in the gallery, `prefers-reduced-motion` respected
- Accessibility: semantic HTML, keyboard focus styles, ARIA labels, Esc closes cart and modal

## Stack
HTML5 · CSS3 (Grid, Flexbox, custom properties, scroll-snap) · JavaScript (ES6+)

## Design
Based on the free **Furniro** template from Figma Community. Font: Poppins (Google Fonts).
